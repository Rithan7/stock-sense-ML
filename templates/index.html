🔬 Wald Test — Feature Significance
The Wald test checks whether each technical indicator has a statistically significant effect on predicting stock movement. A p-value < 0.05 means the feature is significant. The Z-score shows how many standard deviations the coefficient is from zero — the larger the absolute value, the stronger the feature's influence on the prediction.
